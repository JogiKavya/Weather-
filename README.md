# 🌤 AI Weather App

A modern weather website built using **HTML, CSS, and JavaScript** that provides:
- Real-time weather data
- Hourly (time-wise) forecast
- AI-style weather insights
- Clean, responsive UI


## 🚀 Features

- 🔍 Search weather by city name
- 🌡 Current temperature, humidity, wind speed
- ⏰ Hourly forecast (3-hour intervals)
- 🤖 AI-generated weather insight (rule-based)
- 📱 Mobile-friendly and responsive design
- 🎨 Clean and modern UI


## 🛠 Tech Stack

- **HTML** – Structure
- **CSS** – Styling & responsiveness
- **JavaScript** – Logic & API integration
- **OpenWeatherMap API** – Weather data
